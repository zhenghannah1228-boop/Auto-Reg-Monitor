# 一点通链接待填清单 · 四个衍生评估台

> 范围：`emark/cyber_assessment.html`、`emark/cop_assessment.html`、
> `emark/ev_assessment.html`、`emark/ad_assessment.html`（不含 `emark_assessment.html`
> 母工具本身，其法规链接单独维护，见 `docs/emark-tool-维护与变更.md`）。
>
> 这四个工具正文里凡是出现下列法规编号，都会被 `regRefHTML()` 自动扫描并尝试
> 转成可点击链接；`REG_LINKS` 里对应条目现在全部是空字符串 `""`，扫描不到链接时
> 渲染成 `<span class="rl-lk ph">`（灰色不可点的占位文字，`ph` = placeholder）而不是
> `<a>`。要让这些引用变成真正的可点链接，就是把下表「一点通链接」列填上
> 对应法规在一点通平台上的页面 URL，然后写回各文件的 `REG_LINKS` 对象
> （`const REG_LINKS={ "UN R155":"https://...", ... }`）。
>
> 本清单只负责列出"有哪些空位"，不负责生成链接本身——我没有一点通平台的
> 内部 URL 规则，这块需要业主/内容团队去平台里找到对应页面后填入。
> 「说明」列是按公开法规条文口径给的简短提示，帮助确认该填哪条法规的页面；
> 标注"（待核实）"的是我不确定具体内容、不敢瞎写的条目，请核实后再填。

## 填法

每个文件顶部都有一份 `const REG_LINKS={...}` 常量（`cyber_assessment.html`
约第 539 行、`cop_assessment.html` 约第 429 行、`ev_assessment.html` 约第 591 行、
`ad_assessment.html` 约第 502 行），把对应键的空字符串换成一点通链接即可，
不用改其它代码：

```js
const REG_LINKS={
 "UN R155":"https://ydt.example.com/regs/un-r155",   // 填这里
 "UN R156":"",
 ...
};
```
