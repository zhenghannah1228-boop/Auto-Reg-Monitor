# 业务逻辑规格（开发交接 · 逻辑侧）

配套 `data/data_catalog.json`(数据侧)。本文档只写**UI demo 看不出来、逆向容易错**的关键判定逻辑——按此实现,行为即与 demo 一致。每节:目的 / 输入 / 规则 / 陷阱 / 位置。

> 通用红线:所有"判定"只做**呈现与引导**,不产生法律结论;发现规则与法规原文冲突时以原文为准并记录,不擅改。

---

## A. 适用法规圈定 `applicable()`（emark 核心)

- **目的**:据用户角色 + 产品选择,算出适用法规项清单(Step3 的数据源)。
- **输入**:`sel = {role, groups, parts, cats, powers}`;数据 `ITEMS` / `ITEM_CATS`(派生自 `EU_ITEMS.c`)/ `PARTS` / `SPLIT_REGS`。
- **规则**(优先级自上而下):
  1. **若 `sel.parts` 非空**(系统集成商按系统选 / 售后件按部件选):把每个 part id 经 `PARTS` 展开为其 `items`,取这些 item 的记录。part id 不在 PARTS 表则视为原始 item 编码。
  2. **否则**:先按 `sel.groups` 过滤(空=全部 A–H 组);再按角色收敛:
     - `STU`(系统集成商)= 只留 `tc !== 'VEHICLE'`;
     - `AFTER`(售后件)= 只留 `tc === 'EXPLICIT'`;
     - `OEM`(整车厂)+ 选了车型 `cats` = **车型硬收敛**:项的适用车型集(`ITEM_CATS[item]`)与所选车型有交集才留;**车型集为空(通用/rollup)始终留**。
  3. **捆绑项展开**:对每个保留项调 `subItemsOf()`——若该项在 `SPLIT_REGS`(如 D3 防盗=R97/116/161-163、D11 光信号多灯…),展开为每条 UN 法规一行叶子项(item 形如 `D3#97`);否则原样。
- **陷阱**:
  - **车型硬收敛只对 OEM 生效**;STU/AFTER 用 parts 精选,不按车型收敛。
  - `ITEM_CATS` 由 `EU_ITEMS.c` 运行时派生,**不手工维护**;车型范围错误改 `EU_ITEMS.c`(本轮修过 R94/R58/R140/R13 的车型范围,见变更文档 #44/#45)。
  - 动力类型**不参与收敛**(只标注,见 C)。
- **位置**:`emark_assessment.html · applicable()` / `subItemsOf()` / `SPLIT_REGS`。

## B. 大 E / 小 e 判定

- **目的**:每项标"大 E(UNECE·可国际互认)"还是"小 e(仅 EU)"。
- **规则**:项的法规是 **UN Regulation** → 大 E;仅 **EU 条例/指令**(无对应 UN 法规,如 eCall 2017/79、前防护、氢系统材料、酒精锁、ISA、DDAW、欧6/7 排放、MAC 空调)→ 小 e。判定用 `/UN\s*R\s?\d/i.test(reg)`。
- **陷阱**:整车 EU 型批(EU-WVTA)证书号以 e 开头属 EU 框架,但其技术要求大量引用 UN 法规、以部件大 E 为组成部分——"整车 e 证 + 部件大 E 标"并存是常态,别混淆整车层与部件层。
- **位置**:`markBadge()` / `certConclusionCard()`。

## C. 动力类型标注 `powNA()`

- **目的**:按所选动力把不相关的项灰标「本动力通常不适用」——**只标注不删除**(业主定的口径)。
- **规则**:`POWER_SPEC[item]` 定义该项适用的动力集;若用户选了动力(`sel.powers`)且与该集无交集 → 标 N/A。项无 `POWER_SPEC` = 通用,不标。
- **实况(已压测验证)**:BEV→油箱R34/LPG R67/CNG R110/氢R134 标 N/A;FCEV→氢适用、油气 N/A;HEV→油箱适用(有 ICE)、氢气 N/A;GAS→燃气适用、电R100/氢/AVAS R138 N/A。
- **位置**:`powNA()` / `POWER_SPEC`。

## D. 可通行国家 `reachData()`

- **目的**:据角色算「可通行/采信国家」清单(结论卡 ③)。
- **规则**(三分支):
  - **eOnly**(范围全是小 e 项):只在欧盟/EEA 内有效;返回 `{eOnly:true}`。
  - **OEM**(整车):欧盟 27+EEA(`EU_EEA`,英国单列"参照/需转换")+ 采信整车型批(`EMARK_ACCEPT.accepts`)+ 参照(`.refs`)。
  - **零部件/系统**(STU/AFTER):据当前 `applicable()` 命中的大 E 法规集,取各法规的 1958 缔约方并集(`VERDB.byNo[no].parties`,`_cnName()` 抽中文名),按覆盖法规数降序;再叠加 `.refs`(部件级参照,`.accepts` 整车级不进部件名单);缔约方与参照**去重**(`partySet`)。
- **陷阱**:`.own` 档国家(中国/巴西/印尼/伊拉克)**结构上永不进名单**(reachData 只读 accepts/refs/parties,从不读 own)。
- **位置**:`reachData()` / `EMARK_ACCEPT` / `EU_EEA`。

## E. 版本板「法定失效日」优先级 `failCell`

- **目的**:版本时效自查表每系列的失效日列,按可信度择优显示。
- **规则**(优先级,命中即止):
  1. `UNECE_TP[reg][series].c5` → 显示 UNECE Col5「法定失效」(深红,最权威);
  2. `.c5n`(脚注限定)→ 显示日期 + 脚注 ⓘ;
  3. `TP_TEXT[reg]` 原文过渡条款(仅对**非最新、非未来**系列):`kind:'cut'` → 红标「过渡条款截止」(该日起缔约方不再有义务接受);另有更早的 `kind:'late'` → 琥珀虚线「XX 后新发证不保证接受」;
  4. 均无 → 「—」(既有证书持续有效,据 WP.29/1044/Rev.3 §25)。
- **陷阱**:`cut`(不再有接受义务)与 `late`(仅新签发的不保证)**性质不同,别合并**;`TP_TEXT` 的 `max/min` 界定条款覆盖的系列区间。
- **位置**:`openVersionBoard()` 内 failCell 段 / `UNECE_TP` / `TP_TEXT`。

## F. 二选一等效 `ALT_REGS`（如 A8）

- **目的**:某项可用两条法规之一满足(A8 儿童座椅固定点 = R145 **或** R14.07)。
- **规则**:`ALT_REGS[item]=[主, 备]`;`altInfo()` 渲染"二选一等效"提示。
- **位置**:`ALT_REGS` / `altInfo()`。

## G. 智驾级别判定 `judgeLevel()`（ad 工具)

- **目的**:据 7 题问卷判定 SAE 级别 → 对应法规路径。
- **规则**(决策树,顺序敏感,`quiz.q1..q7`):
  1. 未答满 7 题 → `未判定`;
  2. `q7==='yes'`(支持车内无人 AVP)→ **AVP / L4(限定场景)**;
  3. `q3==='nomon'`(系统监控环境)**或** `q4==='eyesoff'`(可脱眼)→ **L3 · ALKS**;
  4. `q1==='sys' && q2==='sys'`(纵横都系统持续控)→ **L2 · DCAS**;
  5. `q1==='sys' || q2==='sys'`(纵或横其一)→ **L1**;
  6. 否则 → **L0–L1**。
- **陷阱**:**"脱手但眼在环"(q4='handsoff')仍是 L2,不是 L3**——L3 的分水岭是"系统监控环境/可脱眼"(q3/q4),不是脱手。顺序不能乱(AVP 先于 L3 先于 L2)。
- **位置**:`ad_assessment.html · judgeLevel()` / `QUIZ` / `PATHS`。

## H. 网安 TARA 定级 `riskOf()`/`calOf()`（cyber · ISO 21434)

- **目的**:每条威胁场景算风险值与 CAL。
- **规则**:
  - **影响** `derivedImpact(t)` = 取 imp{S/F/O/P} 四类里 `SEVRANK` 最高者(Severe>Major>Moderate>Negligible);
  - **可行性** `effFeas(t)` = 若攻击潜力 5 因子(et/ex/kn/wo/eq)全填 → `apFeasKey(apSum)` 映射到 VeryLow/Low/Medium/High;否则用手填 feas;
  - **风险** = `RISK[影响][可行性索引]`(1–5);**CAL** = `CAL_TBL[影响][可行性索引]`(0–4,0=无需 CAL)。
- **陷阱**:必须**影响 + 5 个攻击潜力因子都填**才算"已评"(`riskOf` 才非空);少一个即未评。
- **位置**:`cyber_assessment.html · riskOf/calOf/derivedImpact/effFeas` + 表 `RISK`/`CAL_TBL`/`AP_FACTORS`。

## I. 功能安全 ASIL 定级 `asilOf()`（cyber · ISO 26262）

- **规则**:需 s(严重度 S0–S3)+ e(暴露 E0–E4)+ c(可控性 C0–C3)全填;任一为 0 档 → QM;否则 `sum=sv+ex+ct`,≥10→D,9→C,8→B,7→A,else QM。
- **位置**:`asilOf()` / `SEV`/`EXP`/`CON`。

## J. 合规路径分档 `anchorConfers()` + 四档（index · 13 合规路径)

- **目的**:选定"已满足准入"的锚点国 → 把其余国分四档。
- **规则**:
  - `anchorConfers(anchor)` 据 `STD_FAMILY`(own_full 国→标准族)/`ORG_FAMILY`(组织条目如 GSO→GCC)+ `PATH_BLOCS` 区块归属,推出锚点的**标准族 tokens** 与所属区块;非自有体系且不在区块 → `weak=true`(对外可转移性有限)。
  - 对每个目标国:`hit = !weak && 锚点tokens 与 目标国 external_recognition.recognizes 有交集`。
    - 在锚点区块内(`PATH_BLOCS`)→ **① 一证通行**;
    - `hit && system_type==='recognition'` → **② 采信免测**;
    - `hit && (hybrid||own_full)` → **③ 部分采信减量**;
    - 否则 → **④ 需本地认证**。
- **陷阱**:**GCC 已移出一证通行区块**(GSO 不签发区域整车型批,2026-07 核实);目标国 `recognizes` 缺关键词会落错档(本轮修过沙特缺 `GCC/GSO标准`)。审批周期无精确数据,按"额外认证负担"四档排序。
- **位置**:`index.html · anchorConfers()` / `renderPath()` / `PATH_BLOCS` / `PATH_TOKENS` / `STD_FAMILY` / `ORG_FAMILY`。

## K. 认证体系地图着色 `certGroupOf()`/`certColorOf()`（index · 05 地图）

- **规则**:own_full 按 `STD_FAMILY` 细分标准体系各一色(EU-WVTA/FMVSS/CMVSS/KMVSS/ADR/日本/GB/AIS/EAEU/自有);hybrid/recognition 各一色。中文认证名→底图英文要素名经 `CN2GEO`(84 国)映射;欧盟成员无独立条目者按 EU-WVTA 统一色(`EU_MEMBERS`)。
- **位置**:`certGroupOf()`/`certColorOf()` / `STD_FAMILY` / `GROUP_STYLE` / `CN2GEO`。

## L. 法规对比等效判定（index · 12 法规对比)

- **规则**:核心判定「相同点 = 两侧都对标同一国际标准(UN R/GTR/FMVSS/GB)→ 视为等效条款」。国际标准引用集 `refs` 按数据规则 3.4 正则从法规编号+对标字段提取;对标重合度 = 两侧 refs 的 Jaccard%。
- **位置**:`renderCmp()` / `refs` 提取正则。
