# NCAP 源文件分卷说明

源文件因单个 zip ≤30MB 限制,切成 12 卷。**全部解压到同一个 `sources/` 目录**即可还原完整 8 体系目录树(各卷的内部路径已统一,解压时会自动归位,不会互相覆盖)。

|---|---|---|

| 02 | 中国 C-NCAP 附录(后半)+管理规则+装备技术 | 25.9MB |
| 03 | 中国 智能网联+绿色C-GCAP+CCRT | 18.1MB |

| 06 | 日本 JNCAP(前半) | 24.0MB |

| 08a | 拉美(前半,含 Latin 自有协议) | 14.8MB |
| 08b | 拉美(后半,含 Euro 原始协议) | 16.0MB |
| 09 | 澳洲 ANCAP | 28.2MB |
| 10 | 美国 + 东盟(含评分xlsm)+ 印度 | 23.6MB |

## 解压方法
所有卷解压到同一 sources/ 即可,例如:
```bash
mkdir -p sources
for z in NCAP_*.zip; do unzip -o "$z" -d sources/; done
```
解压后目录结构应为:
```
sources/
├── 中国/   日本/   东盟/   拉美/
├── 澳洲/   欧盟/   美国/   印度/
```
此结构与 CLAUDE.md 中的源文件路径一致(注意 CLAUDE.md 路径以体系名开头,需在 sources/ 下运行,或把 sources/ 内容上提一层)。
